# Product images

Drop product images into this folder using the exact filenames below. The site
will pick them up automatically. Until a file is present, the catalog shows a
clean dark placeholder card with the brand name — nothing breaks.

Recommended: 1200×900 JPG (4:3 aspect), under 200 KB each.

## Filenames the site expects

- `sony-zv-e10.jpg`
- `sony-a6500.jpg`
- `sony-16-50.jpg`
- `sony-35-1.8.jpg`
- `sony-18-105.jpg`
- `yongnuo-yn50.jpg`
- `sony-55-210.jpg`
- `sigma-60-600.jpg`
- `rode-smartlav.jpg`
- `tiffen-nd09-49.jpg`
- `tiffen-nd09-72.jpg`
- `natgeo-tripod.jpg`
- `dji-action-5.jpg`
- `dji-osmo-mobile-6.jpg`

## Workflow

1. **Phase 1 (now):** save manufacturer product shots from the official sites
   under the names above. Each one shows up the next time you reload the page.
2. **Phase 2 (later):** replace each file with a clean, well-lit photo of YOUR
   actual unit on a neutral background — same filename, no code change needed.
